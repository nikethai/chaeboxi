# Project-scoped knowledge

Project knowledge applies only to the relevant project, while approved personal preferences can apply across projects. When a request needs project-specific knowledge and the intended project is unclear, Chaeboxi asks for clarification rather than guessing. This favors separation and correct applicability over a single pool of memories that could silently apply one project's rules to another.
