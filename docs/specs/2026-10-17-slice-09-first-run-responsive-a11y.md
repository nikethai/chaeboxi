# Slice 9: First Run, Window Sizes, Accessibility Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A new user goes from first launch to a Review that is filling, in five steps; the app works at three window sizes; and a screen-reader, keyboard or reduced-motion user can do everything a pointer user can.

**Architecture:** First run is a full-window route (`/first-run`) driven by a small persisted `firstRun` record in settings, so a quit mid-way resumes; it composes the sign-in sections that already exist and the APIs of slices 2, 3, 5 and 7. Window size is one pure function of width (`wide | medium | phone`) exposed as a hook and as `data-layout` on `<html>`; the sidebar, inspector and phone tab bar read it. Accessibility lands as one new piece (`TurnAnnouncer`), checks on 1b's `Sheet` and `Mascot`, and scan tests that keep later code from regressing them.

**Tech Stack:** React 18, TanStack Router (file routes, `routeTree.gen.ts` regenerated by the Vite plugin), Zustand (`settingsStore`, `uiStore`), Mantine 7, Vitest 4 (+ jsdom, Testing Library `fireEvent`), postcss for CSS scan tests, Biome. Capacitor 7 and Tauri Android for the phone shell.

**Spec:** `docs/specs/2026-10-16-ux-flows.md` (flow 1, Screens table rows 1 and 22–24, "Gaps closed on 2026-10-17": Window sizes, Dark mode, Accessibility, Thinking and waiting), `design/dango/README.md` (Layout, Motion, Colour), wireframes FR1–FR5, RS1–RS3, A11Y1, DK1, DK2, EM2 on the "Dango redesign wireframes" canvas, [roadmap](2026-10-17-redesign-roadmap.md).

## Review Focus

- A user upgrading with a model already configured must never see first run; a user who later removes every model sees only step 1, then returns where they were (Task 1).
- Cancelling the folder picker or closing the OAuth browser tab leaves nothing connected and no scope created, and step 2 is still usable (Task 3).
- Resizing across 1200 or 760 px while the inspector sheet or the rail peek is open leaves no orphan scrim; back at wide the inspector is docked again (Tasks 5, 7).
- Esc inside an open Select dropdown in a sheet closes only the dropdown; when the element that opened a sheet is gone (the Review item was approved), focus goes to `#main`, not `body` (Task 6).
- Pressing Stop while the model thinks: the live region says "Stopped before answering." once and the 5 s ticks stop (Task 9).
