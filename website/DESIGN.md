## Vibe

Studio Editorial. Void `#121214`, Satoshi, JetBrains Mono, indigo `#5b63d4`. One hero radial wash (indigo ≤ 12%). No chrome gradients. No sparkles. No Inter / Jakarta / Space Grotesk.

## RNG + overrides

- Hero: Editorial Split
- Type: Satoshi
- Components: inline screenshot chip, provider marquee, principles (not fake quotes)
- Motion: CSS sticky + scale/fade. No GSAP
- Vibe override: Studio Structuralism (dark), not white Soft Structuralism
- Radius: 11 / 16 bezel, not 2rem squircle

## AIDA

Nav island → 2-line H1 split hero → gapless 4-cell bento → sticky desire → download band → footer.

## H1

`Local-first AI copilot.` — `clamp(2.75rem, 4.6vw, 5rem)`, `text-wrap: balance`, max 2–3 lines.

## Bans

Fake testimonials. Universal MCP/computer-use claims. Meta-labels (`SECTION 01`). Picsum. Motion libraries.
