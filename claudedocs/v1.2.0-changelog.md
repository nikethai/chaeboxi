## Sprint 6 — Search & Citations

### Gemini Grounding with Google Search
- Native `google_search_retrieval` tool added to Gemini requests
- Parses `groundingMetadata` (groundingChunks, groundingSupports, confidence scores)
- Converts to `SearchCitation[]` and persists on message
- Settings toggle: "Use Google Grounding when Gemini is selected"
- **Files**: `gemini.ts`, `abstract-ai-sdk.ts`, `stream-text.ts`, `web-search.tsx`

### SearchCitation Type
- `SearchCitation` interface: index, url, title, snippet, favicon, source, accessedAt, relevanceScore
- Source types: `builtin` | `gemini-grounding` | `openclaw` | `mcp`
- Zod schema validation
- **Files**: `session.ts`

### Citation UI
- `CitationBadge` — `[1]` superscript, hover tooltip, click opens URL
- `SourceCard` — favicon + title + domain + snippet
- `SourceCardList` — horizontal ScrollArea above messages
- `remarkTransformCitationLinks` — remark plugin to convert `[N]` patterns to citation links
- **Files**: `CitationBadge.tsx`, `SourceCard.tsx`, `SourceCardList.tsx`, `Markdown.tsx`, `Message.tsx`

### Exa Semantic Search
- Neural/semantic search via `https://api.exa.ai/search`
- `useAutoprompt: true` for query optimization
- API key configuration in web-search settings
- **Files**: `exa.ts`, `web-search/index.ts`, `web-search.tsx`

### Jina Reader
- Page scraping via `https://r.jina.ai/{url}`
- Returns clean markdown, free, no API key
- Setting: "Scrape top results for deeper context"
- **Files**: `jina-reader.ts`

### OpenClaw Provider (Tier 1)
- OpenAI-compatible provider at `http://127.0.0.1:18789/v1`
- Default model: `pi-agent`
- Health check support
- **Files**: `openclaw.ts`, `providers/index.ts`

### Citation Persistence Fix (P1)
- `citations`, `searchQuery`, `searchProvider`, `groundingMetadata` now copied from result to message in `generation.ts`
- Previously only Gemini grounding citations worked; now all providers work
- **Files**: `generation.ts`

## Phase 3 — Polish

### FollowUpSuggestions
- Pill-shaped buttons below search-enhanced assistant messages
- Contextual suggestions: "Tell me more about X", "Compare with alternatives", "Summarize key findings"
- Click auto-sends as new user message
- **Files**: `FollowUpSuggestions.tsx`, `Message.tsx`

### CitationTracker
- Unified citation normalization across all sources
- Deduplication by URL
- Methods: `addFromSearchResults()`, `addFromGrounding()`, `addFromMCP()`, `addFromOpenClaw()`
- `annotateText()` to inject `[N]` markers
- **Files**: `citation-tracker.ts`

### QueryClassifier
- Lightweight pattern-based auto-search detection
- Categories: time-sensitive, factual, current-events, technical, general
- `shouldAutoSearch(query, threshold)` for easy integration
- No LLM calls — keyword/regex matching only
- **Files**: `query-classifier.ts`

## Bug Fixes

### Queue UI Overhaul
- Replaced invisible "Queued (1)" text with `QueuedMessageList` component
- Numbered entries with message preview + file indicator
- Per-item remove button + "Clear all" link
- Stable `EMPTY_QUEUE` reference to prevent infinite re-renders
- **Files**: `QueuedMessageList.tsx`, `InputBox.tsx`, `messageQueue.ts`

### Citation AST Crash
- `remarkTransformCitationLinks` crashed on empty/invalid nodes from regex split
- Early return when no citations, skip empty strings, guard splice
- **Files**: `Markdown.tsx`

### Queue Drain Race Condition
- `submitNewUserMessage` now `await`s `generate()` instead of fire-and-forget
- Prevents race where new messages bypass queuing after drain
- **Files**: `messages.ts`

### History Transfer Metadata
- `getSessionMeta()` now preserves `hidden`, `folderId`, `tags`, `archived`
- Previously these fields were lost on duplicate import skip
- **Files**: `sessionHelpers.ts`
